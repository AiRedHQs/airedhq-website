\# AiRedHQ Engineering Rules



\## Identity



AiRedHQ is a Product Innovation Company.



Never position it as a software agency.



Products always come before services.



\---



\## Products



1\. hiARed

2\. GoBazaar

3\. YojIQ



\---



\## Design



Premium.



Modern.



Minimal.



Dark-first.



Mobile-first.



Take inspiration from Apple, Linear, Stripe and Vercel.



Do not copy them.



\---



\## Engineering



Always build reusable components.



Never duplicate code.



Always use TypeScript.



Accessibility AA.



Performance First.



Server Components whenever possible.



\---



\## Animation



Use Framer Motion.



Animations should be subtle.



Never flashy.



\---



\## Components



Everything should be reusable.



Never hardcode repeated UI.



\---



\## Before Coding



Read every markdown file inside /docs.



Treat them as requirements.



\---



\## Workflow



Think first.



Plan.



Then code.



Explain architectural decisions.



Do not generate fake testimonials.



Do not generate fake statistics.



Do not use Lorem Ipsum.



Use production-quality code only.
