
# GRAPHICS_GUIDE.md

## Visual Style

Overall Style:
Premium, futuristic, product-focused.

## Hero Graphics
- Cinematic gradients
- Abstract 3D forms
- Soft particles
- Minimal wireframes
- Technology-inspired illustrations

## Imagery
- Product screenshots
- Device mockups
- Real people where relevant
- No generic stock photos

## Illustration Style
- Clean isometric
- Soft gradients
- Minimal outlines

## Motion
- Smooth fades
- Subtle parallax
- Micro-interactions
- Performance-first

## Product Color Usage
AiRedHQ: Neutral + dynamic gradients
hiARed: Purple
GoBazaar: Blue
YojIQ: Lime Green

## AI Image Prompt Rules
Generate modern, premium visuals with dark backgrounds, glassmorphism, soft glow, realistic lighting and product-centric composition.

## AI Context
Graphics should support storytelling, not distract from content.
