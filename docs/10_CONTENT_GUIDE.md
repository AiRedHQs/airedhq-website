
# CONTENT_GUIDE.md

## Writing Principles
- Product-first messaging
- Clear, concise language
- Benefit before feature
- No exaggerated claims
- Active voice

## Homepage Messaging
Headline: We Build Products That Solve Real Problems.
Subheading: AiRedHQ designs, engineers, and scales AI-powered products, immersive experiences, and modern software platforms.

## Tone
Professional, modern, optimistic, technically accurate.

## CTA Library
- Explore Products
- Start a Project
- Book a Discovery Call
- View Case Study
- Learn More

## SEO Copy Rules
- One H1 per page
- Natural keyword usage
- Outcome-focused copy
- Short paragraphs
- Accessible readability

## Product Messaging
Introduce:
1. Problem
2. Solution
3. Benefits
4. Proof
5. CTA

## AI Context
Never use placeholder text. Always write as if publishing to production.
